# Password Strength Checker

A simple Python command-line tool that checks how strong a password is.

## What it checks
- Length (at least 8 characters)
- Uppercase letter
- Lowercase letter
- Number
- Special character

## How to run it
```bash
python3 main.py
```

## Example
```
Enter a password to check: abc
Strength: Weak (1/5)
```
